# jstage-picker

J-STAGE から、分野を問わず読み物として面白そうな論文を数件拾い、抄録を読みやすい HTML にして開くツールである。

抄録は、著者が書いたものをそのまま載せる。
AI による要約はしない。
論文を読む練習に使うことを想定しているためである。

## 必要なもの

- Python 3.12 以上
- [uv](https://docs.astral.sh/uv/)（なくても `pip install .` で入る）

外部ライブラリには依存しない。
標準ライブラリだけで動く。

## 使い方

```sh
uv run jstage-picker                 # 5件選んでブラウザで開く
uv run jstage-picker -n 3            # 3件選ぶ
uv run jstage-picker --seed 醤油 苔   # 検索に使う語（種語）を指定する
uv run jstage-picker --llm           # 最終選定だけ Claude に任せる
```

`python -m jstage_picker` でも同じように起動できる。

既定の設定では、J-STAGE へのリクエストが40回ほど発生する。
リクエストの間に1.5秒ずつ待つため、結果が出るまで1分強かかる。

### オプション

| オプション | 既定値 | 内容 |
| --- | --- | --- |
| `-n` | 5 | 選ぶ件数 |
| `--seeds` | 8 | ランダムに選ぶ種語の数（検索 API を呼ぶ回数と同じ） |
| `--seed 語 ...` | なし | 種語を直接指定する。指定すると `--seeds` は使われない |
| `--per-seed` | 4 | 種語ごとに記事ページを開いて抄録を取りに行く件数 |
| `--since` | 1990 | この年以降に出た論文から探す |
| `--llm` | オフ | 最終選定を Claude に任せる |
| `--model` | `claude-haiku-4-5-20251001` | `--llm` のときに使うモデル |
| `-o` | `jstage_picks.html` | 出力する HTML のパス |
| `--no-open` | オフ | 書き出したあとブラウザで開かない |

最終選定では、同じ種語から2件以上は選ばない。
そのため `--seed` で語を1つだけ指定すると、`-n` に関係なく結果は最大1件になる。
複数件ほしいときは、種語を件数ぶん以上指定する。

### Claude に選ばせる

`--llm` を付けると、スコア上位25件の中から Claude が `-n` 件を選ぶ。
環境変数 `ANTHROPIC_API_KEY` が必要である。

```sh
export ANTHROPIC_API_KEY=sk-ant-...
uv run jstage-picker --llm
```

Claude に渡すのは、候補のタイトル、雑誌名、抄録の冒頭600字だけである。
キーが設定されていないとき、または API の呼び出しに失敗したときは、通常のヒューリスティック選定に切り替わる。

## 論文の選び方

1回の実行は、次の順に進む。

1. 種語をランダムに選ぶ。
   種語は「猫」「踏切」「しゃっくり」「河童」のような日常的な名詞で、`src/jstage_picker/seeds.py` に並んでいる。
   具体的な語ほど、意外な分野の論文に当たりやすい。
2. 種語ごとに、年の範囲をランダムに決めて J-STAGE WebAPI で検索する。
3. 検索結果から、タイトルに日本語を含まないもの、既に選んだことのあるもの、学会の予稿集や講演要旨集に載ったものを除く。
4. 残りから `--per-seed` 件を選んで記事ページを開き、抄録、キーワード、本文が無料で読めるかどうかを取り出す。
5. 抄録を採点する。
6. スコア上位25件から、雑誌も種語も重ならないように `-n` 件を選ぶ。

採点では、次の要素を加点または減点する。

- **抄録の長さ**：200字から900字を最も高く評価する。短すぎる抄録は読み応えがないため減点する
- **本文の公開**：無料で本文まで読めるものを優先する
- **タイトル**：「なぜ」「起源」「変遷」「をめぐる」など、問いや由来を扱っていそうな表現があれば加点する
- **専門用語の濃さ**：英字、数字、記号の割合が高いほど減点する
- **定型的な抄録**：「明らかにした」「示唆された」が2回以上出てくると少し減点する

毎回同じ論文ばかり選ばれないように、スコアには小さな乱数を足している。

## 出力と記録

選んだ論文は `-o` で指定した HTML に書き出す。
同じ内容のタイトル、雑誌名、URL を標準出力にも表示する。

選んだ論文の DOI は `~/.jstage_pick_seen.txt` に1行ずつ追記し、次回以降の候補から外す。
記録するのは DOI だけで、本文やメタデータは保存しない。
同じ論文をもう一度候補に戻したいときは、このファイルから該当する行を消す。

## J-STAGE の利用について

[J-STAGE WebAPI 利用規約](https://www.jstage.jst.go.jp/static/pages/WebAPI/-char/ja)の範囲で、非営利かつ個人的に使うことを前提にしている。
J-STAGE に負荷をかけないよう、リクエストは少数に抑え、成功したときも失敗したときも次のリクエストまで1.5秒以上空ける。
`--seeds` や `--per-seed` を大きくすると、そのぶんリクエストの回数が増える。

## ソースの構成

```
src/jstage_picker/
├── cli.py          引数の解析と、検索から出力までの流れ
├── config.py       定数（User-Agent、リクエスト間隔、API の URL など）
├── seeds.py        種語の一覧
├── models.py       Paper（論文）と ArticleInfo（記事ページから取った情報）
├── http_client.py  リクエストの間隔を保証する HTTP クライアント
├── jstage.py       検索 API の XML と記事ページの meta タグの解析
├── scoring.py      候補の絞り込み、採点、重複を避けた選定
├── llm.py          Claude による選定（失敗時はヒューリスティックに戻る）
├── render.py       HTML の生成
└── seen.py         既読 DOI の読み書き
```

種語を増やしたいときは `seeds.py` を、採点の基準を変えたいときは `scoring.py` を編集する。
